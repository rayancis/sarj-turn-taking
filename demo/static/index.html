How decisions reach this page
  1. The page plays the call's two channels from one audio clock and reports its playhead to the local server every ~15 ms.
  2. For each 20 ms frame the playhead reaches, the server does what the kit's harness and server do: the same control messages (scenario_start, agent_utterance_start/end) in the same order, then the 1,280-byte stereo frame, into MySystem.on_frame of the selected version, imported unchanged.
  3. Any decision is validated with the kit's protocol check, stamped with its frame time, and sent back; the page then mutes the agent until the end of that utterance. Pause stops the clock and the feed together; Reset and scenario/model changes start a fresh detector.
  4. Labels are read only by the official scorer, after the decisions exist. Nothing here is pre-scripted.
