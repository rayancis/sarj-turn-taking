# Claude Code: primary implementer

Follow the shared constraints in AGENTS.md. Read PROJECT.md first; it contains the
verified baseline, run commands, source rules and proposed first experiment.

Implement one agreed hypothesis on a focused branch. Preserve the official kit
and the original baseline. Add tests for new behaviour and real failure modes,
not copies of the implementation. Record comparable measurements and limitations.
Keep changes ready for independent Codex review; do not mark your own work as
independently approved. Do not introduce advanced models or cloud services until
the simpler experiment and its errors justify them with the user.
